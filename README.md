# Goal Tracker

A modern, feature-rich goal tracking application built with Next.js, TypeScript, and Tailwind CSS.

## Features

- 🎯 Goal tracking with progress visualization
- 📊 Interactive charts and progress overview
- ✅ Milestone management with drag-and-drop
- 💬 Rich text comment system
- 🏆 Achievement system
- 🔍 Search and filter functionality
- 📱 Responsive design
- ✨ Modern UI with animations

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion (animations)
- Recharts (data visualization)
- React Beautiful DnD (drag and drop)
- React Quill (rich text editor)
- React Toastify (notifications)

## Getting Started

1. Clone the repository:
```bash
git clone [your-repository-url]
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

- `components/GoalTracker.tsx` - Main component containing all the application logic and UI
- `app/` - Next.js app directory with layout and page components
- `public/` - Static assets

## Features in Detail

- **Goal Management**: Create, track, and manage personal or team goals
- **Progress Tracking**: Visual progress bars and charts
- **Milestone System**: Create and manage milestones with drag-and-drop functionality
- **Comment System**: Rich text comments with likes and replies
- **Achievement System**: Track and display achievements
- **Search & Filter**: Search goals and filter by categories
- **Data Persistence**: Local storage integration for data persistence
